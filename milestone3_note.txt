Airline Reservation System: Milestone 3
CSC 3300-002: Jerry Chandler, Teagan Tobias, Logan Wolford
Requires MySQL 8.0.16 or later.
 
Run the files in this order:
1. airline_res_create_tables.sql: creates the database and tables (resets the database)
2. airline_sample_data.sql: loads the sample data
3. views_procedures_triggers.sql: creates the views, function, procedures, and triggers
4. queries.sql: 12 queries; run one at a time (they need steps 1 to 3 first)
5. rule_tests.sql (optional, not required): runs 16 tests of the business rules; all should say PASS.
   To run it again: CALL sp_run_rule_tests();
